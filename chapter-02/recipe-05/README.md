### 代码

如果是段落上的一个函数或片段的代码可以用反引号把它包起来（\`），例如：

```
`printf()` 函数
```

显示效果如下所示：

`printf()` 函数

#### 转义反引号

如果你要表示为代码的单词或短语中包含一个或多个反引号，则可以通过将单词或短语包裹在双反引号(\`\`)中。

```
``Use `code` in your Markdown file.``
```

显示效果如下所示：

``Use `code` in your Markdown file.``

#### 代码区块

你也可以用 ``` 包裹一段代码，并指定一种语言（也可以不指定）：

<pre><code>
```javascript
$(document).ready(function () {
            alert('RUNOOB');
            });
```
</code></pre>


显示效果如下所示：

```javascript
$(document).ready(function () {
            alert('RUNOOB');
            });
```
